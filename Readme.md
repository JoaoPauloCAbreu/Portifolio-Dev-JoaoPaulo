# </Dev.JoaoPaulo>

Landing page de portfólio pessoal feita com HTML e CSS puro — sem frameworks, sem dependências.

![CSS](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)

---

## 📋 Sobre

Portfólio de página única desenvolvido para apresentar minhas habilidades, stack, jornada de aprendizado e informações de contato. O foco foi em estrutura limpa, identidade visual consistente e uso de técnicas modernas de CSS.

## ✨ Funcionalidades

- Layout totalmente responsivo (mobile, tablet, desktop)
- Header fixo com efeito glassmorphism (`backdrop-filter`)
- Card de código animado com floating animation na seção hero
- Seção de timeline para a jornada de aprendizado
- Navegação com scroll suave
- Paleta de cores moderna usando o espaço de cor `oklch()`
- Espaçamentos fluidos com `clamp()`
- Google Fonts: Space Grotesk + JetBrains Mono
- Ícones via [Remix Icon](https://remixicon.com/)

## 🚀 Como rodar

Nenhum processo de build necessário. Basta clonar e abrir.

```bash
git clone https://github.com/JoaoPauloCAbreu/dev.joaopaulo.git
cd dev.joaopaulo
```

Abra o arquivo `index.html` no navegador — ou use a extensão [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) no VS Code.
